Como en cualquier lenguaje de programación poner comentarios en el código es muy sencillo y util.

En Java podemos poner dos tipos de comentarios:

## Comentarios de una sola línea

Los comentarios de una sola línea comienzan con dos barras inclinadas (`//`).

```java
// Esto es un comentario de una sola línea
System.out.println("Hola mundo!");
```

## Comentarios multilínea

Los comentarios de varias líneas comienzan con `/*` y termina con `*/`.

```java
/* Esto es un comentario multilínea,
muy utiles para documentar de forma corta métodos, funciones, etc */
System.out.println("Hola mundo!");
```
